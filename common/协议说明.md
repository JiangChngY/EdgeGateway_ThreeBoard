# 串口二进制协议

所有多字节整数均为小端序。串口默认 `115200 8N1`。

## 帧格式

| 偏移 | 长度 | 字段 | 说明 |
|---:|---:|---|---|
| 0 | 1 | SOF1 | 固定 `0xAA` |
| 1 | 1 | SOF2 | 固定 `0x55` |
| 2 | 1 | Version | 当前为 `0x01` |
| 3 | 1 | Type | 消息类型 |
| 4 | 2 | Sequence | 递增序号 |
| 6 | 2 | Payload Length | 最大64字节 |
| 8 | N | Payload | 负载 |
| 8+N | 2 | CRC16 | Modbus CRC16，覆盖Version到Payload |

## 消息类型

- `0x01` Sensor：F103上报传感器。
- `0x02` Heartbeat：设备心跳。
- `0x10` Command：MP157下发命令。
- `0x11` Command ACK：F103回复命令执行结果。

## Sensor负载（10字节）

| 偏移 | 类型 | 字段 |
|---:|---|---|
| 0 | int16 | 温度，摄氏度×100 |
| 2 | uint16 | 湿度，百分比×100 |
| 4 | uint16 | 光照ADC原始值 |
| 6 | uint16 | 电位器ADC原始值 |
| 8 | uint8 | 有效位：bit0温湿度、bit1光照、bit2模拟量；bit7表示当前数据为合成/演示数据 |
| 9 | uint8 | 报警状态，0/1 |

## Command负载（5字节）

第1字节为命令号，后4字节为有符号参数：

- `0x01` 设置温度阈值，参数单位为0.01℃。
- `0x02` 复位报警，参数忽略。
- `0x03` LED控制，0关、非0开。
- `0x04` 蜂鸣器控制，0关、非0开。

## 构帧错误

兼容接口 `eg_build_frame()` 失败时仍返回0；需要区分原因时使用 `eg_build_frame_ex()`：

- `EG_BUILD_NULL_ARGUMENT`：输出、必要负载或written参数为空。
- `EG_BUILD_PAYLOAD_TOO_LARGE`：负载超过64字节。
- `EG_BUILD_OUTPUT_TOO_SMALL`：输出缓冲区容量不足。
