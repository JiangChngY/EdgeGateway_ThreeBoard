# 协议与网络联调

## 自动测试

Windows PowerShell：

```powershell
python .\tests\run_all.py
```

测试集覆盖CRC16、传感器负载往返、串口分片与噪声重同步、坏CRC恢复、TCP/JSON ACK、必需交付文件、Keil设备与宏定义、Keil/qmake源码引用、Python语法、INI配置、Linux脚本换行符，以及代码审查的关键回归约束。

如果电脑安装了WSL和GCC，还可以直接编译运行C协议测试：

```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic -Icommon \
  common/edge_protocol.c tests/c_protocol_test.c -o /tmp/c_protocol_test
/tmp/c_protocol_test
```

## 模拟i.MX6ULL汇聚端

终端1：

```powershell
python .\tools\imx_test_server.py --host 0.0.0.0 --port 9000
```

把MP157配置中的汇聚地址临时指向电脑IP，可以独立检查TCP断线重连、NDJSON上报和ACK持久队列。

## 模拟MP157上报端

终端1运行参考服务器，终端2运行：

```powershell
python .\tools\mp157_uplink_sim.py --host 127.0.0.1 --port 9000 --count 20
```

每条数据应收到相同序号的 `ok:true` ACK。
