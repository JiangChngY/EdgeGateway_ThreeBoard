# F103编译与烧录

1. 打开 `firmware_f103/Project.uvprojx`。
2. 确认Device为STM32F103C8，宏为 `USE_STDPERIPH_DRIVER,STM32F10X_MD`。
3. 编译目标 `EdgeNodeF103`。
4. 使用ST-Link下载，复位运行。

## 无传感器联调

PA0、PA1悬空会产生跳动数据，不适合稳定演示。至少接两个10k电位器，或将PA0/PA1通过10k电阻接GND。

DHT11读取失败时，默认根据ADC生成演示温湿度。真实DHT11工作稳定后，在 `App/app_config.h` 中改为：

```c
#define EG_USE_SYNTHETIC_ON_DHT_FAILURE 0
```

DHT11数据位通过TIM4直接测量高电平脉宽；协议 `valid_flags` 的bit7表示当前温湿度为合成演示数据。关闭合成兜底后，DHT11失败会清除bit0，MP157显示 `--`。

报警采用锁存消音逻辑：按下复位后不会在下一帧立刻重响，温度低于“当前阈值-1℃”后才自动重新布防。

## 串口自测

先把USB-TTL接电脑串口助手，选择115200/8N1。二进制协议不可直接阅读，可使用逻辑分析仪确认每秒有一帧，或运行 `tools/f103_serial_monitor.py`（需要pyserial）。

## 常见问题

- Keil找不到头文件：确认Include Path包含 `Start;User;Library;BSP;App;../common`。
- DHT11一直失败：检查模块是否有上拉电阻、DATA是否接PB12、供电是否3.3V。
- 蜂鸣器逻辑相反：在 `bsp_outputs.c` 对调PB13置位/复位逻辑。
- Blue Pill板载LED逻辑相反：默认PC13低电平点亮。
