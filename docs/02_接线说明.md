# 接线说明（无需PCB）

## 推荐采购

- 1个CH340、CP2102或FT232的3.3V USB-TTL模块。
- 杜邦线若干。
- 两根网线和一个普通路由器/交换机。
- 正点原子7寸RGB触摸屏原装排线。
- DHT11模块、光敏电阻AO模块、10k电位器模块、有源蜂鸣器模块（均选择已焊排针版本）。

## F103传感器

| 模块 | 模块端 | F103 |
|---|---|---|
| 光敏AO模块 | VCC/GND/AO | 3.3V/GND/PA0 |
| 电位器模块 | VCC/GND/AO | 3.3V/GND/PA1 |
| DHT11模块 | VCC/GND/DATA | 3.3V/GND/PB12 |
| 有源蜂鸣器模块 | VCC/GND/IN | 3.3V/GND/PB13 |

ADC输入不得超过3.3V。模块全部优先使用3.3V供电。

## F103到MP157（推荐USB-TTL）

| F103 | USB-TTL模块 |
|---|---|
| PA9 / USART1_TX | RXD |
| PA10 / USART1_RX | TXD |
| GND | GND |

USB-TTL的USB插头接MP157 USB Host。不要连接USB-TTL模块的5V或3.3V到F103；F103通过自己的USB或ST-Link供电。

MP157启动后检查：

```sh
dmesg | tail -n 30
ls -l /dev/ttyUSB*
```

如果设备名不是 `/dev/ttyUSB0`，修改 `config/mp157.ini`。

## MP157到i.MX6ULL

两块板分别接入同一台路由器。建议固定：

- i.MX6ULL：`192.168.10.2`
- MP157：`192.168.10.3`
- 调试电脑：`192.168.10.10`

先从MP157执行 `ping 192.168.10.2`。

## 7寸屏

断电插拔原装40Pin RGB排线，屏幕只连接MP157。不要使用杜邦线逐根连接RGB信号。先用正点原子出厂Qt镜像确认显示和触摸正常，再部署本项目。

## 安全规则

- 所有接线都在断电状态完成。
- 三块板使用各自原装供电，不互连5V/3.3V电源。
- USB-TTL必须选择3.3V逻辑电平。
- 杜邦线控制在30cm以内并贴上TX/RX/GND标签。
- 不要把TTL接到DB9 RS232、RS485 A/B或CANH/CANL。
