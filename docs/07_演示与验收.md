# 演示脚本与验收

## 基础验收

- [ ] MP157点亮7寸屏，触摸切换三个页面。
- [ ] F103每秒上报，MP157四个数据卡和曲线更新。
- [ ] 温度超过阈值后界面变红、蜂鸣器响。
- [ ] 点击“复位报警”后F103蜂鸣器关闭。
- [ ] 点击LED开/关，F103板载LED响应。
- [ ] MP157历史页面能查询最近100条SQLite记录。
- [ ] i.MX6ULL网页显示网关在线和最新数据。
- [ ] i.MX6ULL数据库持续增加记录。

## 故障演示

1. 拔掉F103到USB-TTL的TX线：3.5秒后MP157显示F103离线。
2. 恢复TX线：界面自动恢复在线。
3. 拔掉MP157网线：屏幕和本地SQLite继续工作，缓存数增加。
4. 恢复网线：TCP自动重连，缓存逐条收到ACK并清空。
5. 保持MP157断网15秒：i.MX6ULL网页标记网关离线。

## 面试讲解顺序

1. 解释三级分层：实时采集、现场HMI、二级汇聚。
2. 展示F103的ADC/DMA和二进制帧协议，说明CRC与重同步。
3. 展示MP157的QSerialPort、SQLite/WAL、触摸控制和离线队列。
4. 展示i.MX6ULL的QTcpServer、心跳判定、HTTP状态页和MQTT扩展。
5. 现场拔网线演示系统降级运行与自动恢复。

## 验收记录

每次上板将结果写入 `docs/上板验证记录.md`，记录日期、板卡丝印、镜像版本、串口设备名、IP、成功项和遗留问题。没有实测的项目不要写“已验证”。
