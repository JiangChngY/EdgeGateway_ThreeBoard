# STM32MP157编译与部署

## 前提

使用与你的正点原子STM32MP157系统镜像匹配的Qt 5.12.x交叉编译SDK。SDK安装路径和环境脚本以对应开发板手册为准。先在板上确认：

```sh
ls /dev/fb*
ls /dev/input/event*
ls /usr/lib/qt*/plugins/sqldrivers/libqsqlite*
```

## 编译

在Ubuntu中安装正点原子MP157 SDK后：

```sh
cd deploy
chmod +x *.sh
./build_mp157.sh /opt/st/stm32mp1/environment-setup-cortexa7t2hf-neon-vfpv4-ostl-linux-gnueabi
```

也可进入 `mp157_hmi` 后手工执行交叉环境中的 `qmake && make -j2`。

## 部署

将二进制和整个仓库传到MP157后，以root执行：

```sh
deploy/install_mp157.sh /path/to/edge-hmi
vi /opt/edge-gateway/config/mp157.ini
systemctl start edge-hmi
journalctl -u edge-hmi -f
```

## 首次手工运行

建议先停止桌面中占用Framebuffer的应用，再运行：

```sh
QT_QPA_PLATFORM=linuxfb /opt/edge-gateway/bin/edge-hmi \
  --config /opt/edge-gateway/config/mp157.ini
```

如果出厂镜像使用EGLFS，将 `linuxfb` 改为 `eglfs`，同时修改systemd服务。

## 串口设备

默认使用USB-TTL的 `/dev/ttyUSB0`。如果界面能扫描到端口但打不开：

```sh
ls -l /dev/ttyUSB0
fuser /dev/ttyUSB0
```

确认没有串口调试程序占用。演示阶段systemd服务以root运行，不受串口用户组限制。

## 阈值同步

真实串口模式下，界面不会在点击按钮时立即保存新阈值。只有F103返回成功COMMAND_ACK后才提交；拒绝、断线或2.5秒超时都会恢复旧值。演示模式不依赖F103，可直接修改本地阈值。

重复运行安装脚本默认保留 `/opt/edge-gateway/config/mp157.ini`。确实需要恢复仓库默认配置时使用：

```sh
deploy/install_mp157.sh --force-config /path/to/edge-hmi
```
