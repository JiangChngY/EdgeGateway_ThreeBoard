# 系统演示

## 完整链路演示

1. MP157启动触屏HMI，切换实时监控、历史数据和设备设置三个页面。
2. F103周期上报温湿度、光照和模拟量，MP157同步更新数据卡片与趋势曲线。
3. 调整报警阈值，展示F103现场报警、蜂鸣器消音和回差重新布防。
4. 在设置页控制F103板载LED，展示Command与Command ACK控制闭环。
5. 在历史页面查询MP157本地SQLite记录。
6. 打开i.MX6ULL状态页，查看网关在线状态、最新数据和汇聚数据库记录。

## 故障恢复演示

1. 断开F103数据链路，MP157在超时后显示采集端离线；恢复连接后界面自动更新。
2. 断开MP157网络，HMI与本地SQLite继续工作，未确认数据进入持久队列。
3. 恢复网络，TCP自动重连，缓存数据按序补传并在收到ACK后删除。
4. 保持MP157离线超过网关超时时间，i.MX6ULL状态页更新其在线状态。

## 系统讲解顺序

1. 说明三级分层：实时采集、现场HMI和边缘汇聚。
2. 展示F103的ADC/DMA、DHT11驱动和二进制帧协议，说明CRC与流式重同步。
3. 展示MP157的QSerialPort、SQLite WAL、触摸控制和断网持久队列。
4. 展示i.MX6ULL的QTcpServer、幂等去重、网关超时检测、HTTP状态页和MQTT扩展。
5. 通过断线与恢复过程说明本地运行、数据补传和ACK闭环。
