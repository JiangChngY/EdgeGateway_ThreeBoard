# 总体架构

## 分层

1. 设备采集层：STM32F103C8T6，固定周期采集并执行控制命令。
2. 现场边缘层：STM32MP157，直接面向用户，负责7寸触摸屏、报警、本地历史和协议转换。
3. 二级汇聚层：i.MX6ULL，无头运行，负责TCP接入、数据备份、在线监测、HTTP状态页和可选MQTT。

## 设计取舍

- F103和MP157之间默认使用USB-TTL模块，而不是直接寻找MP157复用串口引脚。这样无需修改设备树，Linux侧稳定出现 `/dev/ttyUSB0`。
- MP157和i.MX6ULL之间只用网线，通过TCP传输换行分隔JSON（NDJSON）。
- MP157保留本地SQLite和离线队列。i.MX6ULL断开时不影响屏幕和本地控制，恢复后自动补传。
- i.MX6ULL不接屏幕，避免增加LCD切换和两套GUI维护。

## 故障行为

- F103超过3.5秒无数据：MP157界面标记离线。
- TCP断线或ACK超过3秒：MP157保留SQLite队列，3秒后重连。
- MP157超过15秒无数据：i.MX6ULL数据库和网页标记网关离线。
- DHT11未连接：默认使用ADC生成演示温湿度，保证链路可先验证。
